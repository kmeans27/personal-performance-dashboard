# v2.2.2 — the instrument opens

**Status: shipped.** `2.2.2`

[v2.2.1](v2.2.1.md) gave every card an editor. This pass gives every editor a
*control*: the first build was a sheet of labels with the same rail for
everything, the number buried among them, and the logging — the one thing the
sheet exists for — the least considered part of it. Click a card now and you get
an instrument: the value at display size, one sentence saying where it stands, and
a recessed well holding the control that fits the field.

Four rules held throughout:

- **The value is the input.** No separate "exact" box. The big number is the text
  field: click it, the digits are selected, type over them. The gauge follows as
  you type.
- **One control per shape.** A mood is five bars, weight is a scale around the
  goal, a week is seven days, a bed time is the night. Nothing shares a control
  because it happens to be a number.
- **Say each thing once.** The prompt, the target sentence and the footer are
  gone from the sheet; the status line is the card's own gap sentence, and it
  hides itself when it would only repeat the title or the target.
- **Live save, no Save button.** *Done* closes. *Clear today* writes `null`.

## 1. The sheet, rebuilt

```
● BODY                                             10/10   ✕
Slept
7.75 h                                            −   +
Inside 7–9 h
┌───────────────────────────────────────────────────────────┐
│   ═══════════▓▓▓▓▓●▓▓▓────────                            │
│   |     |     |     |     |     |                         │
│   0 h        7–9 h                              12 h      │
│   [6 h] [7 h] [7.5 h] [8 h] [9 h]  [Yesterday 7.75 h]     │
└───────────────────────────────────────────────────────────┘
The body ring rewards the 7–9 h band, not raw hours.
                                   Clear today      [ Done ]
```

- **Head:** category dot, category name, the points chip (`10/10`), a round `×`.
  The chip says *Optional*, *Not in the score* or *No score yet* when the field is
  not priced, instead of the old bare `—` that read like a minus button.
- **Hero:** a 3.3rem number over a hairline baseline, with the unit at 1.25rem.
  It is a real `<input>` for quantities and times: focus selects all, typing
  updates the gauge immediately, `Enter` commits, blur rounds to the field's step
  and reformats (`11200` → `11,200`).
- **Status:** the card's gap sentence, in the accent when the field is scored and
  done ("Inside 7–9 h"), quiet otherwise. Hidden when the server is only repeating
  the prompt or the target (`How was today overall?`, `Target 7–9 h`).
- **Stage:** a `--bg` well, 1px line, 18px radius. It is the only recessed surface
  in the app, and the thing your eye lands on after the number.
- **Footer:** a quiet *Clear today* and one primary pill, *Done*.

## 2. One control per field

| Card | What opens |
| ---- | ---------- |
| **Slept, Screen time, Pickups** | A gauge: the band, round ticks, yesterday’s tick, a 30px knob, and the ends of the axis. The window is the card’s own track (screen time runs 0–8 h, pickups 0–150), so a drag is coarse where it should be and typing can still reach the field’s hard limits. Presets and a dashed **Yesterday** chip underneath. |
| **Steps, Outdoor light** | The same gauge as a bar, with the target tick and its number on the axis (`9,000`). |
| **Weight** | A scale around the goal: ±6 kg, the goal band with a `goal` label, ticks, and yesterday as a dashed chip. The status carries the distance (`0.2 kg above goal`). With no goal, the window centres on today’s reading and the card says so. No fill — a weight is not a quantity filling up. |
| **Mood, Energy** | A five-bar ladder standing on a hairline, the word under each bar, the hero showing the chosen word (`great`). |
| **Deep blocks** | Four doors — *None / One / Two / Three* — each drawn as that many bars. |
| **Greens, Creatine, Read** | Two full-size doors with the word centred and a check in the corner when chosen. |
| **Learned** | The same doors; choosing *Yes* uncovers the note underneath, which saves on its own. |
| **Gym, Alcohol-free** | The trailing seven days as seven mini-rails: day name and date, the count at the right, today tinted, empty days a dim `—`. Drag or use the arrow keys on any day — a past day writes to that day. |
| **Clean day** | Thirty numbered buttons in a 10 × 3 grid; today has the ring, a clean day is filled. Tap to toggle. |
| **In bed** | The 21:00–02:00 night strip, the usual window drawn as a band, yesterday’s tick, and the hour labels. **Now**, **Usual** and **Yesterday** chips set the time in one tap — *Now* only appears when the clock is actually inside the night. `−`/`+` move fifteen minutes; typing keeps the exact minute. |

Two copy fixes came with the controls: deep blocks now says *“Three fills the
ring — a fourth does not add”* (the score does saturate at three, and the old
“capped at four” promised a fourth tile that does not exist), and the bed help no
longer explains the same thing twice.

Counts read like counts now: **1 day / 7 days**, **1 session / 4 sessions**.

## 3. What it taught

- **The exact box was the problem, not the text.** Moving the editable number into
  the hero deleted a control and made the number the control. The sheet got
  shorter and the number got bigger at the same time.
- **A rail is not a universal control.** Weight from 0 to 110 with a 0.1 step is
  one pixel per 0.1 kg — precise only in theory. Six kilos either side of the goal
  makes every tenth a comfortable 5 px. The same reasoning set the window for
  screen time and pickups.
- **Snapping belongs to the pointer, not the data.** The bed editor was rounding
  every write to a quarter hour, so the *Usual 22:33* chip quietly stored 22:30.
  Now drags snap, because a drag cannot be finer than a few pixels, and typing and
  chips keep the minute.
- **A label centred in a band will be sat under.** The usual window’s caption sat
  exactly where the knob lives; it is gone, because the *Usual 22:33* chip already
  says the same thing one line below.

## 4. Verification

- **55 tests** (`uv run pytest -q`) — the payload, scoring and board behaviour are
  untouched.
- **Playwright at 1440×900**, all sixteen cards: every editor opened, screenshotted
  and wrote. Typing `8.25` moved the knob to 0.69 of the rail and stored 8.5 after
  one `+`; a preset wrote; `48` typed into pickups and cleared wrote `null`; the
  seven-day grid wrote a **past** day and the week count followed; a clean cell
  toggled both ways; the bed chips stored 22:33 exactly and typing stored 23:07;
  the arrow keys on a focused rail stepped steps by 100.
- **Playwright at 390×844**: eight editors, no horizontal overflow, no sheet taller
  than the viewport, the footer always reachable, zero console errors.
- **The board is unchanged behind it**: no page scroll at 1440×900, 1920×1080 and
  2560×1440; seven pages × four viewports with no horizontal overflow and no
  console errors; the demo board still refuses to open an editor.
- **Focus**: `Escape` closes the sheet and focus returns to the card head; the
  editor is reachable by keyboard, and every rail shows its focus ring.

## Known limits

- **No undo yet.** Every write is live; reversal arrives with the phone pass
  ([v2.3](../ROADMAP.md#v23--the-phone)).
- **The demo board is a picture** — its cards do not open the editor.
- **The weight goal is set in Settings**, not in the scale. The editor shows the
  distance; it does not move the goal.
- **The hero selects all on focus.** That is the point — typing replaces the value
  — but it does mean a caret placed mid-number takes one extra click.
