# v2.2.3: desktop polish

**Status: shipped.** `2.2.3`

The desktop board finished: the rail stacks the ring, the comparison, the three
next best moves, the week and the Sources card, with no dead space; Main task
joins Attention; notes open as a full-width row under the pair; mood and energy
become one row of chips; the score bar is grouped by category; and a perfect day
gets one quiet moment. The Sources card is a setup nudge, not another settings
page: the steps live in Settings.

Scope: desktop only. The phone is v2.3. One scoring change: the new Attention field in section 2.


## 1. Left rail: no dead space

- Stack from the top, nothing pinned to the bottom: ring (larger), Yesterday | Usual, Next best moves (top 3, read-only, with points, tap scrolls to the card), This week strip, Sources card
- **Sources card:** two rows, Apple Health and Screen Time. Not set up: a "Set up" button that opens the steps in Settings. Once the import endpoint has received data from that source in the last 36 h, the row becomes a quiet "Apple Health, synced 07:42" (use the import's `source` field)
- There is no one-tap connect. Apple Health needs an iOS Shortcut automation that posts to /api/import. Screen Time has no official export, so it needs a Shortcut from a third-party app, or manual entry. The setup steps explain this and the fields stay editable by hand
- The full setup lives in Settings. On Today the Sources card shows only until both sources are set up or the user dismisses it


## 2. Attention: new field "Main task"

- "Did you finish the one thing that mattered most today?" Yes / No, 10 points. On Yes, a note row opens ("What was it?"), same pattern as Learned
- Order in the column: Screen time, Pickups, Main task, Clean day
- Cards size to their content. Never stretch cards to equalize column heights. If a column ends shorter, leave it


## 3. Yes/No pairs and notes

- Read and Learned are identical: same height, Yes/No buttons capped around 48 px and top-aligned, no stretching
- The note field doesn't open inside the card. On Yes, a full-width note row slides in below the pair (spanning both columns). Same for Main task


## 4. Mood and energy

- One row of 5 chips each, about 90 px tall per card (today about 290). Prompt above the chips. Labels in readable contrast. Still "Not in the score"


## 5. Card headers

- Label above value on every card (small label, big value below). Full-width cards currently put them on one line, half cards stack them


## 6. Ring and blocks

- Remove "/100". The number is centered and scaled to fit 3 digits inside the inner ring
- At 100 (all rings closed): a one-time-per-day "perfect day" moment. The rings complete with a slow light sweep, the glow swells and settles slightly brighter than before, and the number pulses once. No confetti. Respect reduced motion
- Deep blocks: filled blocks are solid, the next block is a dashed outline with an accent and a "+". Today a block looks filled at 0


## 7. Score breakdown bar

- Group segments by category in column order, with labels above each group (Body 84, Mind 50, Attention 63)
- Earned = category color (teal, violet, blue). Remaining = same color at about 15%. Not logged = dashed outline
- Field name and points on hover, and as text on the widest segments. The Next best move segment gets an amber outline


## 8. Contrast and color

- Check the dimmest text (axis labels, "Not in the score", points, chip labels) against 4.5:1
- Push the Mind hue toward violet so it separates from Attention blue
