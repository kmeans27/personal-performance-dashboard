# v2.2 — log it on the board

**Status: shipped early, inside [v2.1.2](v2.1.2.md).** `2.2.0`

This release was planned as the one that removed the second input surface: every
field answered where it is read, no sheet, no modal, no list of fields behind a
button.

It shipped earlier than planned. The [v2.1.2](v2.1.2.md) brief asked for a board
where "the cards are the only inputs" — and that layout cannot be drawn without
making the cards live. So the gesture layer, the inline save, the keyboard path and
the learned note all landed with the home screen rework, and the quick-log sheet
and `tile.js` were deleted. No separate `2.2.0` build exists; the patch that
finished the idea is [v2.2.1](v2.2.1.md).

| What shipped | Where |
| ------------ | ----- |
| Drag / tap a range track, tap a bar, tap weekly dashes, tap blocks, tap the thirty dashes, flip Yes/No, tap a 1–5 step, drag the night's ends | `card.js` |
| Optimistic update from the returned day payload; no new endpoint | `card.js`, `board.js` |
| Arrow keys nudge, `Home`/`End`, `Space`/`Enter` flips, `role="slider"` / `role="switch"` / `aria-checked` | `card.js` |
| The learned note is an inline text field in the card, saved on Enter or after typing stops | `card.js` |
| The quick-log sheet and `tile.js` are gone; one component owns every instrument | `web/js/components/` |

The rule held: **an answer should cost one gesture, and never a modal.**

What did *not* ship here — undo, and the pointer and focus audit — moved to
[v2.3](v2.3.md), because it is a pass of its own rather than a leftover.
